
# 1. Contexto administritativo 

Nuestro sistema apoya una estructura centralizada con ejecución local.

Por qué: La base de datos con las reglas de negocio (tiempos de alerta de vencimiento, catálogo de productos y cálculo de perdidas) se administra de forma centralizada para asegurar que todos los supermercados de la cadena sigan las mismas normas de calidad. Sin embargo, la operación es local: cada cajero, monitor o encargado gestiona las alertas y retiros de su propia tienda en tiempo real.
