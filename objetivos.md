     # ¿ Que Problema Soluciona ?

     el problema que afrontan los pequeños supermercado,  es la falta de control en sus alimentos, y en base a eso nuestro proyecto se enfoca en solucionar ese problema de raiz, busca tener un control de la fecha de cauducidad  de cada alimento, asegurandole al cliente, recibir un  producto en buen estado.
       
    # ¿ A Que Nivel De Desicion Impacta ?

       el nivel de desicion al que impacta,: es el sistema operativo ya que el programa se basa en un control diario de cada producto, un monitor se encargara de supervisar el programa diariamente,
       
    # ¿ Que Decisiones Permitiria Tomar ?

       permitiria tomar decisiones operativas, ya que permite gestionar en tiempo real tipo de producto y fecha de caducidad 

    # ¿ Que Pasaria Si No Existiera Ese Sistema ?

si ese sistema no existiera,  los clientes de aquellos supermercados no quedarian satisfechos con sus compras debido a que  el porducto puede estar vencido, y esto    conlleva 
 a que los dueños pierdan dinero, y  tener sanciones por no  cumplir la normativas de sanidad 


 # APLICACION AL PROYECTO


 # Ojetivo General Del sistema  

   implementar un sistema de monitoreo y control de fechas de los productos que  permita identificar los productos que estan proximos caducar 

# Dos Objetivos Especificos

 *  mejorar las ventas de los supermercados
 *  generar confianza y tranquilidad de los productos que compran

# Nilvel De Decision  Principal Que Impacta

 * Operativo: el es un sistema que permite un monitoreo en  tiempo real en todos los productos del supermercado

# Caracteristicas Criticas Que Debe Cumplir 

* Precision:  tenemos que saber la fecha exacta de cada producto y  la cantidad  de aquel, para no  tener ningun problema

#  ¿Que Decision Permitiria Tomar?

* Advertir al trabajador encargado cuando el producto esta caducado con el objetivo de retirar el producto
